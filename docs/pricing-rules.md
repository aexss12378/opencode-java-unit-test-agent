# 訂單折扣規格

`OrderPricingService.calculateDiscount` 必須符合下列規則：

1. 小計不可為 `null` 或負數；顧客編號不可為空值或空白字串。
2. 折扣政策回傳的百分比不可為 `null`，且必須介於 0 到 100 之間（含端點）。
3. 折扣金額的計算公式為「小計 × 折扣百分比 ÷ 100」。
4. 回傳金額固定為小數點後兩位，使用 `HALF_UP` 四捨五入。
5. 輸入或折扣政策結果違反上述規則時，拋出 `IllegalArgumentException`。

本文件是定價行為的正式依據。既有測試與目前實作若和本文件衝突，以本文件為準。
